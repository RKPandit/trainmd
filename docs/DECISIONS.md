| 2026-09-10 | Ground-truth evidence is the minimal sufficient set: root cause + observable symptom | An operator's evidence refs are the MINIMAL set to localize the fault — root cause (e.g. config key) plus observable symptom (e.g. metric anomaly or traceback) — not every artifact in the causal chain. Decided against adding a `code_span` on train.py model-construction lines to `shape_mismatch` evidence: the config key IS the root cause and the traceback IS the symptom; the code between them is mechanism.
